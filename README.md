## Index of Questions

| S.No | Week | Question No. | Question Description |
|------|------|---------------|----------------------|
| 1 | Week 1 | Q1 | Given an array of non-negative integers, design a linear algorithm and implement it using a program to determine whether a given key element is present in the array or not. Additionally, find the total number of comparisons performed for each input case. |
| 2 | Week 1 | Q2 | Given an already sorted array of positive integers, design an algorithm and implement it using a program to determine whether a given key element is present in the array or not. Also, find the total number of comparisons performed for each input case. |
| 3 | Week 1 | Q3 | Given an already sorted array of positive integers, design an algorithm and implement it using a program to determine whether a given key element is present in the array or not using Jump Search technique. |
| 4 | Week 2 | Q1 | Given a sorted array of positive integers containing duplicate elements, design an algorithm and implement it using a program to determine whether a given key element is present in the array or not. If the key element is present, also find the number of copies (frequency) of the given key in the array. |

| 6 | Week 2 | Q3 | Given an array of non-negative integers, design an algorithm and implement it using a program to count the number of pairs of integers such that their difference is equal to a given key (K). |
| 7 | Week 3 | Q1 | Given an unsorted array of integers, design an algorithm and implement it using a program to sort the array using Insertion Sort. Also determine the total number of comparisons and shifts. |
| 8 | Week 3 | Q2 | Given an unsorted array of integers, design an algorithm and implement it using a program to sort the array using Selection Sort. Also determine the total number of comparisons and swaps. |
| 9 | Week 3 | Q3 | Given an unsorted array of positive integers, design an algorithm and implement it using a program to determine whether the array contains duplicate elements or not using sorting. |
| 10 | Week 4 | Q1 | Given an unsorted array of integers, design an algorithm using Divide and Conquer approach to sort the array. Also determine the total number of comparisons and inversions. |
| 11 | Week 4 | Q2 | Given an unsorted array of integers, design an algorithm to sort the array by partitioning it into two subarrays based on a randomly chosen pivot element. Also determine the total number of comparisons and swaps. |
| 12 | Week 4 | Q3 | Given an unsorted array of integers, design an algorithm and implement it using a program to find the Kth smallest or Kth largest element in the array. |
| 13 | Week 5 | Q1 | Given an unsorted array of alphabets containing duplicate elements, design an algorithm and implement it using a program to determine which alphabet has the maximum number of occurrences and print it along with its frequency. |
| 14 | Week 5 | Q2 | Given an unsorted array of integers, design an algorithm and implement it using a program to determine whether two elements exist such that their sum is equal to a given key element. |
| 15 | Week 5 | Q3 | Given two sorted arrays of integers, design an algorithm and implement it using a program to find the list of elements that are common to both arrays. |
| 16 | Week 6 | Q1 | Given a directed or undirected graph, design an algorithm and implement it using a program to determine whether a path exists between two given vertices using DFS. |
| 17 | Week 6 | Q2 | Given a graph, design an algorithm and implement it using a program to determine whether the graph is bipartite or not using BFS. |
| 18 | Week 6 | Q3 | Given a directed graph, design an algorithm and implement it using a program to determine whether a cycle exists in the graph or not. |
| 19 | Week 7 | Q1 | Design an algorithm and implement it using a program to compute the shortest path and distance from each vertex to the source vertex using Dijkstra’s Algorithm. |
| 20 | Week 7 | Q2 | Design an algorithm and implement it using a program to compute the shortest paths from a source vertex using Bellman-Ford Algorithm. |
| 21 | Week 7 | Q3 | Given a directed graph with a specified source and destination vertex, design an algorithm and implement it using a program to find the weight of the shortest path from source to destination with exactly k edges. |
| 22 | Week 8 | Q1 | Design an algorithm and implement it using a program to find the minimum cost required to connect all cities using Prim’s Algorithm (Minimum Spanning Tree). |
| 23 | Week 8 | Q2 | Implement the same problem using Kruskal’s Algorithm to determine the minimum spanning cost of connecting all cities. |
| 24 | Week 8 | Q3 | Design an algorithm and implement it using a program to determine the maximum budget required to connect all cities (Maximum Spanning Tree). |
